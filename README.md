# 📄 Resume Analyzer

Free tool to check how well your resume matches a job description.
Upload a PDF/TXT (or paste text), paste the job description, and get:

- Overall match score
- Matched and missing keywords
- ATS and quality checks (contact info, links, length, action verbs, results)
- A list of suggested fixes

Everything runs in the browser. Resumes are never uploaded anywhere.

## Files
- `index.html`: page structure
- `style.css`: design (light and dark mode)
- `script.js`: PDF reading and scoring logic

## Deploy free on GitHub Pages
1. Create a new public repo (e.g. `resume-analyzer`) and upload these 4 files.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then **Save**.
4. After about a minute your link is live: `https://YOUR-USERNAME.github.io/resume-analyzer/`

## Run locally
Open `index.html` in a browser.
